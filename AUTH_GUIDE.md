## 🚀 Как использовать

### Шаг 1: Откройте страницу авторизации
```
http://localhost/auth.html
```

### Шаг 2: Регистрация нового пользователя
1. Нажмите "Зарегистрироваться"
2. Заполните форму:
   - **Имя пользователя** (минимум 3 символа)
   - **Email** (действующий email)
   - **Пароль** (минимум 8 символов)
   - **Подтверждение пароля**
   - **Страна** (опционально)
3. Нажмите "Зарегистрироваться"
4. Проверьте email для подтверждения (если Supabase требует)

### Шаг 3: Вход в систему
1. На главной странице авторизации заполните:
   - **Email**: Ваш email
   - **Пароль**: Ваш пароль
2. Нажмите "Войти"
3. Вы будете перенаправлены на главную страницу

## 💻 Функционал авторизации

### Регистрация
```javascript
const result = await signUp(email, password, username)
// Создает нового пользователя в Supabase Auth
// Автоматически создает профиль в таблице users
```

### Вход
```javascript
const result = await signIn(email, password)
// Аутентифицирует пользователя
// Сохраняет сессию в localStorage
```

### Выход
```javascript
const result = await signOut()
// Завершает сессию
// Очищает localStorage
```

### Проверка авторизации
```javascript
const { data: { user }, error } = await getCurrentUser()
// Возвращает текущего авторизованного пользователя
// Если пользователь не авторизован, возвращает null
```

## 🛡️ Безопасность

### На стороне сервера (Supabase):
- 🔐 Пароли хешируются
- 🔐 JWT токены для сессий
- 🔐 Row Level Security для защиты данных
- 🔐 Email верификация (опционально)

### На стороне клиента:
- 🔐 Пароли не сохраняются
- 🔐 Токены в localStorage (защищено)
- 🔐 HTTPS для безопасности

## ⚠️ Важные замечания

### ПЕРЕД РАЗВЕРТЫВАНИЕМ:

1. **Проверьте таблицы в Supabase**:
   - Таблица `users` должна быть создана
   - Должны быть созданы индексы

2. **Включите Email подтверждение** (опционально):
   - Settings → Auth → Email Templates
   - Это обезопасит аккаунты от фейковых email

3. **Добавьте Redirect URLs**:
   - Settings → Auth → Redirect URLs
   - Добавьте: `http://localhost:3000/index.html`
   - И ваш production URL

4. **Настройте RLS политики** (обязательно):
   ```sql
   ALTER TABLE users ENABLE ROW LEVEL SECURITY;
   
   CREATE POLICY "Users can view own profile"
   ON users FOR SELECT
   USING (auth.uid() = id);
   ```

## 🆘 Решение проблем

### Проблема: "Invalid email"
**Решение**: Проверьте формат email (должен содержать @)

### Проблема: "Weak password"
**Решение**: Пароль должен быть минимум 8 символов

### Проблема: "User already registered"
**Решение**: Используйте другой email или войдите существующим аккаунтом

### Проблема: Перенаправление не работает
**Решение**: Убедитесь, что в Supabase добавлен redirect URL
