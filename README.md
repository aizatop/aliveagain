# Путешествия по Миру

Красивый сайт о путешествиях в постельных тонах с интегрированным мессенджером.

## Особенности

- 🌍 **Страны**: Япония, Франция, Италия, Лондон с видео и описаниями
- 💬 **Мессенджер**: Чат для путешественников с Supabase интеграцией
- 🎨 **Дизайн**: Современный UI в постельных оттенках
- 📱 **Адаптивность**: Полностью отзывчивый дизайн
- ✨ **Анимации**: Плавные переходы и параллакс эффекты

## Технологии

- HTML5
- CSS3 с современными градиентами
- JavaScript (ES6+)
- Supabase для бэкенда
- Font Awesome для иконок

## Структура

```
personal-website/
├── index.html          # Основная страница
├── styles.css          # Стили в постельных тонах
├── script.js           # JavaScript функционал
└── README.md           # Документация
```

## Функциональность

### Страны
- Япония: видео и достопримечательности (Фудзияма, Киото, Токио)
- Франция: видео и достопримечательности (Эйфелева башня, Лувр)
- Италия: видео и достопримечательности (Колизей, Венеция)
- Лондон: видео и достопримечательности (Биг-Бен, Тауэрский мост)

### Мессенджер
- Авторизация через email
- Общий чат для всех пользователей
- Системные уведомления
- Эмодзи поддержка
- Сохранение сообщений в Supabase

## Настройка Supabase

1. Создайте таблицу `messages` в Supabase:
```sql
CREATE TABLE messages (
    id TEXT PRIMARY KEY,
    user_id TEXT,
    user_name TEXT,
    text TEXT,
    timestamp TIMESTAMP,
    type TEXT DEFAULT 'user'
);
```

2. Включите Realtime для таблицы `messages`

## Запуск

Откройте `index.html` в браузере. Сайт будет работать локально.

## Авторизация

Для входа в мессенджер используйте любой email и пароль (демо-режим).
